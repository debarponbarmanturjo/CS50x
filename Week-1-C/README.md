# Week 1: C Programming

Introduction to low-level C programming, fundamental logic, compilation, and command-line execution for **CS50x Week 1**.

---

## 📚 Key Concepts Learned
* **Syntax & Mechanics:** Headers (`#include <stdio.h>`), data types (`int`, `string`), and main function entry points.
* **Flow Control:** Conditional statements (`if`/`else`), loops (`while`, `for`, `do-while`).
* **Algorithmic Logic:** Implementation of greedy algorithms for optimal change calculation.
* **Command Line & Compilation:** Using `clang` / `make` to compile source code into machine executables.

---

## 🛠️ Code Included
* `hello.c` – Basic input/output and string formatting.
* `mario.c` – Nested loops for building pyramid structures.
* `cash.c` – Greedy algorithm implementation to calculate the minimum number of coins for change.

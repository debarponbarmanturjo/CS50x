# Week 0: Scratch – Endless Runner Game

An arcade-style endless runner built in Scratch for **CS50x Week 0**. Test your timing and reflexes as obstacles approach faster over time!

🔗 **Live Project Link:** [Play on Scratch](https://scratch.mit.edu/projects/1381478023/)

---

## 🎮 Game Overview

* **Objective:** Dodge cacti and rocks to survive as long as possible. Earn points continuously while running and set the highest score possible.
* **Genre:** Endless Runner
* **Difficulty:** Normal

---

## 🕹️ Controls & How to Play

1. Click the **Green Flag** to load the game.
2. Click the **Start** button to begin running.
3. Press **Spacebar** to jump over incoming obstacles.
4. Time your jumps carefully as the game speed increases!

---

## 🧩 Key Implementation Details

* **Custom Logic:** Uses custom blocks and variables to calculate player movement, collision detection, and dynamic score tracking.
* **Obstacle Spawning:** Randomly selects between cacti and rocks with varied speed scaling to challenge the player.
